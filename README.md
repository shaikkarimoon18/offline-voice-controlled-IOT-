# Offline Voice-Controlled IoT Automation System Using Edge AI

## Project Overview
This project is an offline voice-controlled home automation system that uses Edge AI technology to control electrical appliances without requiring an internet connection. It recognizes voice commands locally and operates appliances such as lights and fans.

## Objectives
- Develop a smart home automation system using voice commands.
- Enable appliance control without internet connectivity.
- Process voice commands locally using Edge AI.
- Improve privacy, convenience, and reliability.

## Key Features
- Offline voice recognition.
- Voice-based appliance control.
- Controls two electrical appliances: Light and Fan.
- Local voice processing.
- Internet-independent operation.

## Hardware Components
- Raspberry Pi 3 Model B+
- Microphone Module
- Relay Module
- 16×2 LCD Display
- Light Bulb
- DC Fan
- Power Supply

## Software and Technologies
- Python
- Raspberry Pi OS
- Edge AI
- Internet of Things (IoT)
- Voice Recognition

## Working Process
1. The user gives a voice command through a microphone.
2. The system processes the voice input locally.
3. The speech recognition system identifies the command.
4. The command is processed by the controller.
5. The corresponding appliance (Light or Fan) is switched ON or OFF.

## Applications
- Smart Home Automation
- Assistive Technology
- Offline Appliance Control
- Smart Electrical Systems

## Project Outcome
Successfully developed an offline voice-controlled automation system to operate two electrical appliances using simple voice commands.
